Скрипт для поиска веб-атак в логах Nginx

Мой пет-проект по автоматизации задач для аналитика SOC. Написала скрипт на Python, который проверяет файлы access.log, находит следы взлома с помощью регулярных выражений и собирает общую статистику по атакующим.

Что умеет ловить скрипт:
- SQL-инъекции: кавычки, UNION, SELECT, конструкции типа OR 1=1 в запросах.
- XSS: попытки прокинуть теги скриптов или функции alert.
- Поиск секретов: подсвечивает, если сканеры ищут бэкапы вроде .bak, .env, .git или файлы config.

Новая фича (Агрегация данных):
Теперь скрипт не просто спамит алертами, а считает количество вредоносных запросов с каждого IP-адреса. В самом конце анализа он выводит сводную таблицу — ТОП самых активных хакеров, которые атаковали сервер.

Стек технологий:
Python 3, встроенные модули re и os (работает сразу, ничего дополнительно устанавливать не нужно).

Как запустить проект локально:
1. Положить файлы parser.py and access.log в одну папку.
2. Открыть консоль в этой папке и ввести команду: python parser.py

Пример вывода статистики в конце работы:

ТОП ХАКЕРОВ (Количество зафиксированных атак):
IP-адрес: 192.168.1.120 -> Атак: 2
IP-адрес: 11.22.33.44 -> Атак: 1
