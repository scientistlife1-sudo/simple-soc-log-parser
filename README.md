Скрипт для поиска веб атак в логах Nginx

Мой пет-проект по автоматизации задач для (аналитика SOC). Написала скрипт на Python, который проверяет файлы access.log и с помощью регулярных выражений находит IP-адреса, которые пытаются сканировать или взломать сайт.

Что умеет ловить скрипт:
- SQL-инъекции: кавычки, UNION, SELECT, конструкции типа OR 1=1 в запросах.
- XSS: попытки прокинуть теги скриптов или функции alert.
- Поиск секретов: подсвечивает, если сканеры ищут бэкапы вроде .bak, .env, .git или файлы config.

Стек технологий:
Python 3, встроенные модули re и os (работает сразу, ничего дополнительно устанавливать не нужно).

Как запустить проект локально:
1. Положить файлы parser.py и access.log в одну папку.
2. Открыть консоль в этой папке и ввести команду: python parser.py

Пример вывода при обнаружении атаки:
ALERT Обнаружена подозрительная активность!
- Атакующий IP: 192.168.1.120
- Тип угрозы: SQL-Injection
- Сам запрос: GET /search.php?id=1
- Код ответа: 200
